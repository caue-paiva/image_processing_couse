# Processamento de Imagens

Este projeto contém exercícios e problemas de processamento de imagens em Python.

## Bibliotecas permitidas

Resolver os problemas utilizando **apenas** as seguintes bibliotecas:

- `numpy`
- `scipy`
- `imageio`

Qualquer outra biblioteca (ex: OpenCV, Pillow, scikit-image) **deve ser aprovada pelo usuário antes do uso**.
