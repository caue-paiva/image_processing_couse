Foi isso mesmo, a Pompom comeu o exercício 01, mas eu tirei uma foto dela com a língua para fora, será que vocês conseguem encontrar onde está o segredo?

Nesse exercício vocês vão fazer a decodificação de uma mensagem escondida em uma fotografia. A mensagem foi escrita usando código ASCII sobre os valores dos pixels. Temos três mensagens, uma em cada canal. As mensagens todas começam com ""segredo: " e terminam com ";". Imprima em ordem a mensagem dos segredos nos canais vermelho, verde e azul (R, G e B). O arquivo que vocês devem ler se chama "pompom_segredo.bmp".

DICA: em Python ord() converte caracteres para inteiros de acordo com a tabela ASCII e chr() converte inteiros para caracteres de acordo com a tabela ASCII
